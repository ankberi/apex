# Introduction

## About This Workshop

In this workshop, you will add advanced data management features to the Employee Self-Service Portal and Talent Acquisition Portal applications. The earlier modules used simple DML processes to save and retrieve data. This module adds APEX Collections, REST Data Sources, and a path toward externally available API endpoints.

Estimated Workshop Time: 30 minutes

### Objectives

In this workshop, you will:

- Build an Employee Self-Service onboarding wizard that stages data in an APEX Collection.
- Store onboarding documents across separate collection rows before committing them to database tables.
- Create a REST Data Source for public holidays and synchronize it into a local table.
- Add public holidays to the Leave Calendar.
- Build a Talent Acquisition Portal offer wizard that stages offer data in an APEX Collection.

## Applications

- **Employee Self-Service Portal (ESS)**: The primary application for onboarding and leave calendar updates.
- **Talent Acquisition Portal (TAP)**: The secondary application for offer wizard processing.

## Prerequisites

- Access to an Oracle APEX workspace.
- The ESS and TAP applications from earlier modules.
